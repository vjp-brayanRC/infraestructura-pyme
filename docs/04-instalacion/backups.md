# Gestión de Backups

## Copias de seguridad

| Tipo de Backup | Frecuencia | Ubicación |
|----------------|------------|------------|
| Completa       | Semanal    | NAS        |
| Incremental    | Diaria     | Servidor   |
| Base de datos  | Cada 12h   | Cloud      |

## Pasos del proceso
1. Generar copia
2. Comprimir archivos
3. Subir al almacenamiento

## Recomendaciones
- Verificar integridad
- Mantener copias externas
- Automatizar tareas
