# Base de Datos

## Descripción

El servidor de base de datos almacena y gestiona la información utilizada por las aplicaciones del sistema.

## Motores utilizados

| Motor | Puerto | Estado |
|--------|---------|---------|
| MySQL  | 3306    | Activo  |
| MariaDB| 3306    | Activo  |

## Funciones principales
- Almacenamiento de datos
- Gestión de usuarios
- Copias de seguridad
- Consultas SQL

## Backups programados
1. Backup diario incremental
2. Backup semanal completo
3. Verificación automática de copias

## Seguridad
- Contraseñas cifradas
- Acceso restringido
- Firewall configurado
- Monitorización de accesos
